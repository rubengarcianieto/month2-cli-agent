# month2-cli-agent

Month 2 of the SNAIL study plan: a hand-built async client for the Claude
API, a tool-calling loop and a command-line assistant.

## Status

Just started. Nothing is implemented yet.

## Setup

Requires Python 3.14 and [uv](https://docs.astral.sh/uv/).

    uv sync
    cp .env.example .env

## Run the tests

    uv run pytest -v
